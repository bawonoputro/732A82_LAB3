# 732A82 Lab 3 — Deep Learning (Linköping University)

This repository contains my work for **Lab 3** in the course **732A82** at Linköping University. The main assignment is implemented in the Jupyter notebook(s) and is shared here as part of my portfolio.

> **Collaboration note:** This lab assignment was completed as a **group of two**.

## Repository Structure
- `CNN_Lab.ipynb` — main lab notebook with the full assignment.
- `CNN_Lab_check_ori.ipynb` — reference/check notebook.
- `utilities.py` / `utilities_ori.py` — helper functions used by the notebooks.
- `images/` — figures and assets.

## How to Run
1. Clone the repository.
2. Create a Python environment (e.g., `venv` or `conda`).
3. Install common notebook dependencies (e.g., `numpy`, `matplotlib`, `torch`, etc.).
4. Open the notebook in Jupyter and run the cells.

```bash
git clone https://github.com/bawonoputro/732A82_LAB3.git
cd 732A82_LAB3
```
